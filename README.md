# Bloom - Habit Tracker App

Bloom is a full-stack habit tracking application designed to help users build consistency by breaking long-term goals into small, trackable daily actions.

## Features
- User Authentication (Signup/Login)
- Habit tracking system
- Streak monitoring
- Clean and responsive UI

## Tech Stack
- React (Vite)
- Supabase (Auth + Database)
- Tailwind CSS

## How to Run
npm install  
npm run dev
